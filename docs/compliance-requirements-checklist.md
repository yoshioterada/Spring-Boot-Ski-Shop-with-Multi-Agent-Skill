# コンプライアンス要件チェックリスト — 法務部門判断依頼書

> **プロジェクト**: SkiShop E-Commerce Microservices Platform
> **作成日**: 2026-03-19
> **版**: 1.0
> **ステータス**: 法務部門レビュー待ち
> **出典**: Gate 1-5 統合レビュー — compliance-reviewer 指摘 (C:3 H:4 M:3 L:2)

## 1. 背景

本プロジェクトは EC マイクロサービスプラットフォームであり、以下のデータを取り扱う:

| データ種別 | 対象サービス | 保存先 | PII 含有 |
|-----------|-------------|--------|----------|
| ユーザーアカウント (氏名, メール, パスワードハッシュ) | authentication-service, user-management-service | PostgreSQL | ✅ |
| 住所・電話番号 | user-management-service | PostgreSQL | ✅ |
| 注文履歴・配送先 | sales-management-service | PostgreSQL | ✅ |
| 決済情報 (トランザクションID, 金額) | payment-cart-service | PostgreSQL | ⚠️ 間接PII |
| ポイント残高・取引履歴 | point-service | PostgreSQL | ⚠️ 間接PII |
| AI チャット履歴 | ai-support-service | MongoDB | ✅ |
| 商品閲覧・検索ログ | ai-support-service | MongoDB | ⚠️ 行動データ |

## 2. 法務判断が必要な項目

### 2.1 [Critical] 同意管理メカニズム (C-01)

**現状**: ユーザー登録時の同意取得メカニズムが未実装。利用規約・プライバシーポリシーへの明示的同意フローなし。

**判断依頼事項**:
- [ ] ユーザー登録時に取得すべき同意の種類と範囲
  - 利用規約への同意
  - プライバシーポリシーへの同意
  - マーケティング目的のデータ利用への同意 (opt-in / opt-out)
  - AI による行動分析へのオプトイン
- [ ] 同意の撤回手段 (Web UI? メール?) および対応期限
- [ ] 同意バージョン管理の要否 (ポリシー改定時の再同意)
- [ ] 未成年ユーザーの保護者同意の要否

**実装上の影響**: authentication-service にユーザー同意テーブル追加、登録 API に consent パラメータ追加が必要

---

### 2.2 [Critical] PII データ保持ポリシー (C-02)

**現状**: データ保持期間が未定義。全データが無期限に保持される設計。

**判断依頼事項**:
- [ ] データ種別ごとの保持期間

| データ種別 | 提案保持期間 | 法務判断 |
|-----------|-------------|---------|
| アクティブユーザーアカウント | 無期限 (退会まで) | □ 承認 / □ 変更: _____ |
| 退会ユーザーデータ | 30日後に匿名化 | □ 承認 / □ 変更: _____ |
| 注文履歴 | 7年 (税法要件) | □ 承認 / □ 変更: _____ |
| 決済トランザクション | 7年 (税法要件) | □ 承認 / □ 変更: _____ |
| AI チャット履歴 | 1年 | □ 承認 / □ 変更: _____ |
| 商品閲覧ログ | 90日 | □ 承認 / □ 変更: _____ |
| セキュリティログ | 1年 | □ 承認 / □ 変更: _____ |
| ポイント取引履歴 | 5年 | □ 承認 / □ 変更: _____ |

- [ ] データ匿名化の方法 (物理削除 / 論理削除 / 仮名化)
- [ ] 会計監査用データの保持義務との両立方法
- [ ] バックアップ内のデータの保持期間

---

### 2.3 [Critical] 越境データ移転の法的根拠 (C-03)

**現状**: ai-support-service が OpenAI API を使用。ユーザーのチャット内容が OpenAI (米国) のサーバーに送信される。

**判断依頼事項**:
- [ ] OpenAI へのデータ送信に対する GDPR/APPI 上の法的根拠の確認
  - Standard Contractual Clauses (SCC) の締結要否
  - Data Processing Agreement (DPA) の締結状況
  - OpenAI の SOC 2 / ISO 27001 認証の確認
- [ ] ユーザーへの事前通知の範囲 (プライバシーポリシーへの記載内容)
- [ ] EU 居住者のデータを OpenAI に送信可能か
- [ ] OpenAI API に送信するデータの範囲制限 (PII のマスキング要否)

**実装上の影響**: AI サービスに PII マスキングフィルタの追加が必要になる可能性

---

### 2.4 [High] データ主体の権利 (C-04)

**現状**: GDPR 第 15〜22 条に基づくデータ主体の権利を行使する API が未実装。

**判断依頼事項**:
- [ ] 対応が必要な権利の範囲

| 権利 | GDPR 条文 | 対応要否 | 法務判断 |
|------|----------|---------|---------|
| アクセス権 (データの確認) | 第 15 条 | 推奨 | □ 必要 / □ 不要 |
| 訂正権 (データの修正) | 第 16 条 | 推奨 | □ 必要 / □ 不要 |
| 削除権 (忘れられる権利) | 第 17 条 | 推奨 | □ 必要 / □ 不要 |
| 処理制限権 | 第 18 条 | 検討 | □ 必要 / □ 不要 |
| データポータビリティ権 | 第 20 条 | 検討 | □ 必要 / □ 不要 |
| 異議申立権 | 第 21 条 | 検討 | □ 必要 / □ 不要 |
| プロファイリング拒否権 | 第 22 条 | 推奨 | □ 必要 / □ 不要 |

- [ ] 権利行使リクエストへの対応期限 (GDPR: 1ヶ月以内)
- [ ] 本人確認の方法 (ログイン済みの場合 / メールでの場合)

**実装上の影響**: user-management-service にデータエクスポート / 删除 API の追加が必要

---

### 2.5 [High] AI プロファイリングのオプトアウト (C-05)

**現状**: ai-support-service が商品レコメンデーションおよびセマンティック検索を提供。ユーザー行動データに基づくプロファイリングが行われている。

**判断依頼事項**:
- [ ] AI レコメンデーションがプロファイリングに該当するか
- [ ] プロファイリングの事前通知が必要か (利用目的の明示)
- [ ] オプトアウト機能の提供義務があるか
- [ ] AI による意思決定の透明性確保の要件 (説明可能 AI の必要性)
- [ ] 13 歳未満のユーザーに対する AI 機能の制限要否

---

### 2.6 [High] ROPA (Record of Processing Activities) (C-06)

**現状**: 処理活動記録が作成されていない。

**判断依頼事項**:
- [ ] ROPA の作成義務があるか (従業員 250 人未満でも特定条件で義務)
- [ ] ROPA の管理体制 (DPO の任命要否)
- [ ] 処理活動の記録範囲と更新頻度

---

### 2.7 [High] PIA/DPIA (Privacy Impact Assessment) の実施 (C-07)

**判断依頼事項**:
- [ ] DPIA の実施義務があるか (AI プロファイリングがトリガー)
- [ ] DPIA の実施範囲 (AI サービスのみ / 全サービス)
- [ ] DPIA 実施のスケジュールと責任者
